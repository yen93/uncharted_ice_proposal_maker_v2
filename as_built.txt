OVERVIEW
- Turns a client's demo-call notes into a tailored "Uncharted Ice" sales proposal
  deck. TWO run modes sharing the same helpers + output:
  (A) Interactive /skill (make-uncharted-ice-proposal) — Claude drives it from a
      pasted Drive link; best quality.
  (B) Automated pipeline (python main.py) — drains a Supabase queue behind a
      user-configured API trigger; uses OpenAI for the transcription + tailoring
      steps Claude does interactively.
- Strategy: copy a master template deck, then edit ONLY the client-specific slides
  in place (preserving the deck's exact design/highlights) and leave the finished
  slides untouched. In-place edits use scoped Slides `replaceAllText`, which keeps
  every surrounding text run's styling — the fix for v1's per-word-highlight loss.
  Then swap the client logo and email the link to Liv.

SLIDE MAP (1-indexed; in config.py)
- TAILOR (retext in place, keep design): 1, 2, 3, 5, 6, 7, 12
- VERBATIM (leave untouched): 4, 8, 9, 10, 11, 13

SCRIPTS
- v2_tools.py — CLI the skill AND the cloud routine shell out to; one operation
  per subcommand, each prints JSON. Subcommands: fetch-notes, make-folder,
  move-file, copy-template, save-text, dump-slides, apply-edits, replace-logo,
  thumbnails, email-proposal, queue-list (unprocessed Supabase rows), queue-done
  (mark a row processed). Accepts raw IDs or full Drive/Slides URLs.
  Requires: .env (Google OAuth; + Supabase for queue-list/queue-done).
- config.py — loads .env + project_vars.txt; extracts PROJ_DRIVE_FOLDER_ID and
  V2_TEMPLATE_ID, holds the slide map, the client-logo image IDs
  (CLIENT_LOGO_IMAGE_IDS), the notification recipient (NOTIFY_EMAIL, default
  liv@myadventuregroup.com.au), and Google scopes (drive, presentations,
  gmail.send).
- src/google_clients.py — builds Drive + Slides + Gmail API clients from the
  refresh token.
- src/drive_service.py — create_client_folder (folder named the bare client name,
  reuse-if-exists), move_file_into_folder (parent swap; copy fallback if not
  movable), duplicate_template, download_file_bytes (exports Google-native files to
  PDF), upload_file.
- src/slides_service.py — dump() (per-slide + per-USED-layout, per-shape, per-RUN
  text with colours/bold/size), apply_edits() (scoped replaceAllText via
  pageObjectIds; a slide_id OR a layout_id can be targeted; reports occurrences),
  replace_logo() (replaceImage on CLIENT_LOGO_IMAGE_IDS with a public URL,
  CENTER_INSIDE; filters to IDs present in the deck), thumbnails() (getThumbnail
  -> PNG for visual verification).
- src/gmail_service.py — send_email() sends the "proposal ready" notification via
  the Gmail API as the account owner.
- oauth_setup.py — one-time OAuth consent to mint GOOGLE_REFRESH_TOKEN into .env.
  Normally unnecessary (token reused from v1). Requires: GOOGLE_CLIENT_ID/SECRET.

AUTOMATED-PIPELINE SCRIPTS (mode B)
- main.py — entrypoint; calls pipeline.run_once(). The API trigger invokes this.
- pipeline.py — orchestrator: reads unprocessed Supabase rows and, per row, runs
  the skill's exact steps (transcribe demo_notes_link -> folder -> move notes +
  save transcription -> copy template -> tailor -> logo swap -> email Liv -> mark
  row processed). Per-row try/except; marks every row (success/needs_review/error).
- src/notes_service.py — transcribe(bytes, mime, additional_notes) via OpenAI
  vision -> structured fields (folds in the row's additional_notes).
- src/slides_tailor.py — build_edits(fields, additional_notes, dump) via OpenAI ->
  highlight-safe find/replace edits mapped into slides_service.apply_edits format.
  Critical rule: a `find` never spans a highlight boundary but may replace a
  highlighted run in full.
- src/supabase_service.py — get_client(), list_unprocessed(), mark_row_processed().
- src/llm_client.py, src/logo_service.py — copied from v1 (OpenAI tool-call helper;
  favicon-URL logo guess).

- (B) Cloud routine "uncharted-ice-proposal-maker-v2"
  (trig_016A8ahwJy4x7DKjxFhTmGh5 at claude.ai/code/routines), cron "45 * * * *"
  (hourly at :45 UTC), Default environment env_01DYHNjMesGeuq9ABo7W6m6f, model
  claude-sonnet-5, repo yen93/uncharted_ice_proposal_maker_v2. It is CLAUDE-DRIVEN:
  the routine's own Claude agent writes .env (Google + Supabase only — NO OpenAI),
  drains the queue via `python v2_tools.py queue-list`, and for each row does the

  vision, tailors highlight-safe, swaps logo, emails Liv) using the v2_tools
  helpers, then `queue-done`. Secrets are embedded in the routine prompt (the
  cloud clone has no .env), same pattern as the v1 fleet.
- (C) python main.py (a.k.a. /run-uncharted-ice-pipeline) — the OpenAI-based
  automated pipeline (pipeline.py + notes_service/slides_tailor). Still present as
  a fallback but the cloud routine (B) no longer uses it, because gpt-5.6-luna was
  too weak at handwriting OCR (missed a clearly-written client_org). Prefer the
  Claude-driven routine.

  NOT use OpenAI. Reused from v1.

  proposal_demo_notes_email_logs queue. Service key in .env (gitignored). Reused
