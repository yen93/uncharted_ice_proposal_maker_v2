OVERVIEW
- Turns a client's demo-call notes into a tailored "Uncharted Ice" sales proposal
  deck. EVERYTHING IS CLAUDE-DRIVEN — no OpenAI / LLM-API dependency anywhere; Claude
  transcribes the notes, writes the edits, and reads the bonus checkboxes itself.
  Two ways to run it, sharing the same helpers + output:
  (A) Interactive /skill (make-uncharted-ice-proposal) — Claude drives it from a
      pasted Drive link. Authoritative definition of the process.
  (B) Automated cloud routine (claude.ai/code/routines) — a Claude agent drains a
      Supabase queue hourly and does the same steps per row. /run-uncharted-ice-
      pipeline is the manual, on-demand version of the same drain.
- Strategy: copy a master template deck; edit the client-specific slides IN PLACE
  with scoped Slides `replaceAllText` (preserves every surrounding run's styling —
  the fix for v1's per-word-highlight loss); apply structural changes (delete the
  framework slide, keep only offered bonuses) LAST by objectId; swap the client logo;
  email the link to Liv; mark the queue row done.

SLIDE MAP (indices on the freshly-copied 13-slide deck; authoritative list in the skill)
- TAILOR (retext in place): 1, 2, 3, 4, 6, 7, 12 + the cover LAYOUT (tagline/date).
- DELETE (last, by objectId): 5 "THE PROGRAM FRAMEWORK" always; bonus slides 9/10
  (and intro 8) conditional on the notes' ADD BONUS VALUE ticks.
- VERBATIM: 11 (testimonials), 13 (closing), + kept bonus slides.

SCRIPTS
- v2_tools.py — the ONLY CLI; the skill AND the cloud routine shell out to it; one
  operation per subcommand, each prints JSON. Subcommands: fetch-notes, make-folder,
  move-file, copy-template, save-text, dump-slides, apply-edits, delete-slide,
  replace-logo, thumbnails, email-proposal, queue-list, queue-done. Accepts raw IDs
  or full Drive/Slides URLs. Requires: .env (Google OAuth; + Supabase for queue-*).
- config.py — loads .env + project_vars.txt; PROJ_DRIVE_FOLDER_ID, V2_TEMPLATE_ID,
  slide-map constants (TAILOR_SLIDES, VERBATIM_SLIDES, ALWAYS_DELETE_SLIDE_IDS,
  BONUS_SLIDES, BONUS_INTRO_SLIDE_ID), CLIENT_LOGO_IMAGE_IDS, NOTIFY_EMAIL (Liv),
  Google scopes (drive, presentations, gmail.send), Supabase queue config.
- src/google_clients.py — Drive + Slides + Gmail API clients from the refresh token.
- src/drive_service.py — create_client_folder, move_file_into_folder (copy fallback),
  duplicate_template, download_file_bytes (exports Google-native files to PDF),
  upload_file.
- src/slides_service.py — dump() (per-slide + per-USED-layout, per-RUN text/colours),
  apply_edits() (scoped replaceAllText via pageObjectIds; slide_id OR layout_id;
  reports occurrences), delete_slide() (deleteObject by objectId or index),
  replace_logo() (replaceImage on CLIENT_LOGO_IMAGE_IDS, filters to present IDs),
  thumbnails() (getThumbnail -> PNG).
- src/supabase_service.py — get_client(), list_unprocessed(), mark_row_processed().
- src/gmail_service.py — send_email() ("proposal ready" notification, as account owner).
- oauth_setup.py — one-time OAuth consent to mint GOOGLE_REFRESH_TOKEN into .env.
  Normally unnecessary (token reused from v1). Requires: GOOGLE_CLIENT_ID/SECRET.
